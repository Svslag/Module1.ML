# Проект 3 — Уровень дохода (Adult Census)

Учебный проект по классификации годового дохода на данных переписи населения США. Задание разделено на три части согласно блокам A, B и C.

## Структура проекта

| Часть | Содержание | Ноутбук |
|---|---|---|
| **A — Базовый** | Пропуски, подготовка данных, Logistic Regression, Accuracy и Confusion Matrix | [Part_A_Basic.ipynb](A_Basic/Part_A_Basic.ipynb) |
| **B — Основной** | EDA, выбросы, Pipeline без утечки, две модели, кросс-валидация и подбор порога | [Part_B_Main.ipynb](B_Main/Part_B_Main.ipynb) |
| **C — Продвинутый** | Дисбаланс классов, анализ ошибок по группам, ограничения модели | [Part_C_Advanced.ipynb](C_Advanced/Part_C_Advanced.ipynb) |

В каждой папке есть собственный README с кратким описанием. Каждый ноутбук запускается самостоятельно: он импортирует библиотеки и при отсутствии adult.csv скачивает датасет из UCI.

## Общие файлы

- `income_level_project.ipynb` — исходный общий ноутбук со всеми разделами.
- `download_data.py` — отдельный скрипт загрузки Adult Census.
- `requirements.txt` — список необходимых Python-библиотек.

## Установка и запуск

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python download_data.py
jupyter notebook
```

После установки откройте нужный ноутбук из папки A_Basic, B_Main или C_Advanced и выполните ячейки сверху вниз.

## Ограничения

Это учебный эксперимент, а не система принятия кредитных решений. Доход не равен кредитоспособности. Исторические данные могут содержать смещения; перед реальным применением потребовались бы дополнительные проверки качества, справедливости, правовых ограничений и безопасности.
