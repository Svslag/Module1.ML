# Проект 3 — Уровень дохода (Adult Census)

Учебный проект по классификации годового дохода на данных переписи населения США.

## Данные

Используется датасет `adult.csv` (32 561 запись). Целевая переменная `income`:
- `>50K` — класс 1;
- `<=50K` — класс 0.

Положите исходный файл `adult.csv` в корневую папку проекта рядом с ноутбуком.

## Содержание проекта

- Первичный анализ данных: структура, пропуски, распределение целевого класса.
- Предобработка: заполнение пропусков внутри Pipeline, OneHotEncoder для категориальных признаков, StandardScaler для числовых.
- Разделение train/test со стратификацией.
- Сравнение моделей и кросс-валидация StratifiedKFold(5).
- Метрики классификации, подбор порога и анализ ошибок.
- Проверка качества на отдельных группах и обсуждение ограничений применения модели.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Откройте `income_level_project.ipynb` и выполните ячейки последовательно.

## Ограничения

Это учебная модель, а не инструмент принятия кредитных решений. Датасет исторический, содержит социально-демографические признаки и может отражать смещения. Метрики на этой выборке не подтверждают справедливость модели или её пригодность для реального банковского скоринга.
