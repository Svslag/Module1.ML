# Проект 3 — Уровень дохода (Adult Census)

Учебный проект по классификации годового дохода на данных переписи населения США.

## Состав проекта

- `income_level_project.ipynb` — Jupyter Notebook с выполнением базового, основного и продвинутого блоков.
- `adult.csv` — исходный датасет (32 561 запись).
- `requirements.txt` — зависимости Python.

## Данные

Целевая переменная `income`:
- `>50K` — класс 1;
- `<=50K` — класс 0.

Поместите `adult.csv` в ту же папку, что и ноутбук.

## Запуск

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
jupyter notebook
```

Откройте `income_level_project.ipynb` и выполните ячейки по порядку.

## Что рассматривается

- EDA: пропуски, типы данных, распределение классов.
- Предобработка в Pipeline и ColumnTransformer без утечки данных.
- OneHotEncoder для категориальных и StandardScaler для числовых признаков.
- Logistic Regression и вторая модель; StratifiedKFold(5).
- Метрики заказчика, выбор порога классификации.
- Дисбаланс классов, анализ ошибок и сравнение методов.
- Ошибки на разных группах и ограничения использования признаков.

## Ограничения

Это учебный эксперимент, а не система принятия кредитных решений. Данные исторические, могут содержать социальные смещения. Метрики на этой выборке не доказывают справедливость модели или её пригодность для реального банковского скоринга.
